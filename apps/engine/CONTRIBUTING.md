# CONTRIBUTING

## Cognotate Engine Server

### Get Base Help Info

In project root:

- `bun dev:cli server --help`

In current workspace:

- `bun dev server --help`

### Test Workflow

1. use `run`, start engine server
2. use `status`, check current state
3. Execute your testing context
4. Observe results and collect logs

## TEST Base Rule

> DO NOT FIX ISSUES. ONLY REPORT THEM.

### Debugging

- Check logs (home directory)
- Describe actual behavior
- Identify possible causes (if any)

### Reporting

A valid report should include:

- what happened
- how to reproduce
- relevant logs
- possible causes (optional)

> Good reports are more valuable than premature fixes.
