# AGENTS.md

## CORE BEHAVIORAL PATTERNS

1. BEFORE STARTING ANY TASK, ALWAYS INVESTIGATE EXISTING ISSUES AND PULL REQUESTS FIRST  
   Use `gh issue list` or `gh pr list` to find related discussions.

2. WHEN YOU ENCOUNTER A BLOCKER OR USEFUL INSIGHT, SHARE INTERMEDIATE THINKING IMMEDIATELY  
   Post it in the relevant discussion thread.

3. WHEN COMPLETING ANY COMMIT OR PULL REQUEST, ALWAYS LINK TO THE RELATED ISSUE  
   Use keywords such as `Closes #123` or `Related to #456`.

4. BEFORE ASSERTING ANY TECHNICAL CLAIM, ALWAYS VERIFY IT FIRST  
   Use `--help`, deepwiki, or official documentation.

## SAFETY RULES

- BEFORE RUNNING ANY UNFAMILIAR OPERATION, ALWAYS RUN `[command] --help` FIRST.
- BEFORE RUNNING ANY COMMAND, CONFIRM YOU ARE IN THE CORRECT PROJECT DIRECTORY.
- BEFORE USING COMMANDS THAT CHANGE HISTORY OR REMOVE DEPENDENCIES, BE EXTREMELY CAUTIOUS.
- WHEN STUCK, CONSULT THE `share/` DIRECTORY FIRST.

NOTE: These patterns and rules take precedence over all other instructions in the project.
